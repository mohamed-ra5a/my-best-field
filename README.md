# FuturePath

### Career Discovery Platform

FuturePath is a modern web application designed to help students and young professionals discover career paths that match their interests, strengths, and preferences.

The platform includes an interactive career quiz, personalized career recommendations, skill roadmaps, salary insights, and a clean dashboard experience.

---

## About The Project

Choosing a future career can be confusing for many students. FuturePath was created to make career exploration easier and more interactive through a simple and modern interface.

Users answer a set of questions, and the system analyzes their responses to suggest suitable career paths along with useful learning guidance.

---

## Features

- Interactive career quiz
- Career match percentage system
- Personalized career recommendations
- Career statistics and charts
- Suggested majors and job paths
- Skill roadmap suggestions
- Dashboard for saved careers
- Dark and light mode toggle
- Responsive design for different devices
- Local storage support

## How It Works

1. The user starts the career quiz.
2. The application analyzes the selected answers.
3. A matching score is calculated for different career paths.
4. The top career matches are displayed with:
   - Match percentage
   - Suggested majors
   - Job opportunities
   - Important skills
   - Salary expectations
   - Learning roadmap
5. Users can save careers to their dashboard.
